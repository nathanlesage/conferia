# Searching for Events

At top of the schedule, you can find a search field. Type a search string in
there to search for specific events. The display will automatically update to
only show you events matching this query.

The function searches everything, such as titles, abstracts, authors, or
locations. The search is case-insensitive, meaning that both "title" and "TITLE"
will match "Title." Furthermore, you do not have to add diacritics to any
characters, since the library will automatically perform normalization. This
means that searching for "karoly takacs" will find "Károly Takács."

If your view mode is set to compact, this will only search the current day. Use
the arrow keys in the day selector to switch days while searching, or switch to
the full view to search all events at the same time.
